# Классификация ориентации текста 0° / 180°

## Результат

Итоговый результат на лидерборде:

- **1 − Brier = 0.94759798**
- **Brier = 0.05240202**

В тестовой выборке — 20 000 изображений.

## Идея решения

Задача решалась как бинарная классификация ориентации текстовой строки:

- класс `0` — текст ориентирован на 0°;
- класс `1` — текст ориентирован на 180°.

В решении использованы две модели классификации ориентации текста из PaddleOCR:

- `PP-LCNet_x1_0_textline_ori`;
- `PP-LCNet_x0_25_textline_ori`.

Обе модели запускались на CPU.

### 1. TTA с поворотом на 180°

Для каждого изображения модель запускалась дважды:

1. на исходном изображении;
2. на изображении, предварительно повернутом на 180°.

Если `p_original` — вероятность класса 180° для исходного изображения, а `p_rotated` — вероятность класса 180° для повернутого изображения, то оценка после TTA вычислялась как:

```text
p_tta = (p_original + (1 - p_rotated)) / 2
```

Такой приём использует симметрию задачи: после поворота исходная ориентация и класс 180° меняются местами.

### 2. Объединение двух моделей

TTA-оценки двух моделей объединялись в logit-пространстве. Использовались веса:

```text
PP-LCNet_x1_0 : 0.59
PP-LCNet_x0_25: 0.41
```

То есть сначала вероятности преобразовывались в logit, после чего вычислялось взвешенное среднее:

```text
z = 0.59 * logit(p_tta_x1) + 0.41 * logit(p_tta_x025)
```

### 3. Temperature scaling

Для итоговой вероятности использовалось temperature scaling с:

```text
T = 0.36
```

Финальная вероятность класса 180° вычислялась как сигмоида от `z / T`.

## Эксперименты

В процессе решения сравнивались отдельные модели, TTA, разные способы объединения моделей и значения температуры.

Результаты проверенных конфигураций на лидерборде:

| Конфигурация | 1 − Brier |
|---|---:|
| x1.0 + x0.25 + TTA, T = 0.37 | 0.94756180 |
| x1.0 + x0.25 + TTA, T = 0.50 | 0.94671345 |
| x0.25-only, T = 0.37 | 0.92852895 |
| Adaptive ensemble | 0.93900258 |
| **x1.0 + x0.25 + TTA, T = 0.36** | **0.94759798** |

Таким образом, финальной была выбрана конфигурация с двумя моделями, 180° TTA, logit-ансамблем `0.59 / 0.41` и температурой `T = 0.36`.

Для дополнительных экспериментов также использовался небольшой синтетический набор изображений с русским и латинским текстом. Он применялся для проверки идей ансамблирования и калибровки, но не использовался как источник разметки тестовой выборки.

## Валидация и воспроизводимость

Основная оценка качества проводилась по метрике соревнования `1 − Brier Score`.

При подборе архитектуры и способов объединения моделей использовались отдельные эксперименты на синтетических данных. Финальные параметры также проверялись по результатам отправок на лидерборд. Истинные метки тестовой выборки не использовались и вручную тестовые изображения не размечались.

Все случайные операции в экспериментальном коде выполнялись с фиксированным seed `42`.

Для воспроизведения финального результата необходимо запустить `solution_final.ipynb` на предоставленных организаторами тестовых данных. Notebook выполняет полный inference-пайплайн и создаёт файл `submission.csv`.
